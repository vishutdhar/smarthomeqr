Where the Lutron Caseta HomeKit code is

Turn the hub over. The Caseta HomeKit code is on the bottom of the Smart Hub, and it is the only code in the system.

Checked against the makers' own pages on 3 November 2026.

Where the code is

The bottom of the Smart Hub
Lutron: enter the HomeKit setup code on the bottom of your Smart Hub. Lutron now calls the Smart Bridge the Smart Hub. The step lives under the integration settings in the Lutron app, Apple HomeKit.
Dimmers and switches
Have no HomeKit code. They join through the hub: once the hub is in Apple Home, its dimmers, switches, plugs and shades appear there. Lutron says Pico remotes and standard keypads do not, which is normal and not a failed pairing.
Lost
Lutron publishes no recovery for a lost hub code. Keep the hub paired; if it ever has to be reset and the label is unreadable, Lutron support is the route.
