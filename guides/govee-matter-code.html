Where the Govee Matter code is

Govee keeps the code in two places: on the product, and on the device's settings page in the Govee Home app.

Checked against the makers' own pages on 3 November 2026.

Where the code is

On the product or in the app
Govee: find the QR code or Matter device number on the product or the Device Settings page in the Govee Home app. Owners of light strips report the printed one on a white band on the power cord.
The first 15 minutes
First time Matter setup must happen within 15 minutes after the product is powered on.
A second controller
Once a device is added to one controller, the setup code that came with the product cannot be used for the second commissioning. Generate a new code from the first controller.
