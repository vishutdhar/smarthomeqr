Matter pairing code not working: the six causes

A Matter code that is read correctly can still be refused. The makers' own pages point at these six causes, and each has its own fix.

Checked against the makers' own pages on 3 November 2026.

Work down the list

1. The device is already paired to another ecosystem
The printed code works at first setup and after a factory reset only. Once Google Home has the device, Apple Home needs a share code from Google Home, not the sticker. Open the first app and look for Linked Matter apps and services (Google), Turn On Pairing Mode (Apple), Other Assistants and Apps (Alexa) or Share with other services (SmartThings).
2. The pairing window closed
A new device waits for its first pairing for a limited time, then stops advertising; TP-Link, Govee, Kwikset and Sengled each quote about 15 minutes. Power it off and on, or for a Kwikset Halo Select press Resume Setup in the Kwikset app, and try again straight away.
3. The share code expired
A code shown by an app to add a second ecosystem lasts minutes: 15 for Alexa, about 3 for Google Home per TP-Link. Apple Home waits 5 minutes before it will make another. Generate it again and use it at once.
4. A digit was misread
The last digit of an 11 digit code is a check digit. Paste the code into the decoder: if it fails the check, one digit is wrong, and 0 against 8, 1 against 7 and 3 against 8 are the usual swaps on a worn label.
5. No hub for a Thread device
A Matter over Thread device needs a Thread border router that the ecosystem can use. Apple lists HomePod mini, HomePod (2nd generation), Apple TV 4K (3rd generation, Wi-Fi and Ethernet) and compatible third party border routers, and says an iPhone 15 Pro or later on iOS 18 can control Thread accessories without one. Alexa needs a Thread enabled Echo, and Google Home a Thread border router from Google's list, which names specific models such as Nest Hub (2nd generation), Nest Wifi Pro, the Google TV Streamer and the Google Home Speaker, while Nest Audio and Nest Mini are listed without Thread; both makers publish the model lists, linked below. Amazon's advice when you have no Thread Echo is to set the device up in another Thread ecosystem first and share it to Alexa.
6. The device is not actually in pairing mode
Locks and bridges often need a button press or an app step first. Kwikset Halo Select converts to Matter from Lock Settings, Matter Integration in the Kwikset app before its label does anything. SwitchBot Hub 2 must be reset before Apple Home will take it. Check the maker's page for the step your device needs.

What the messages mean

Setup code incorrect, or check the setup code and try again
Causes 1, 2 and 4. Rule out cause 4 with the decoder, then check whether the device is already paired somewhere, then power cycle.
Accessory already added, or already in another home
Cause 1. The device still belongs to another ecosystem or a previous owner. Share it from there. A factory reset is the other way, but only with the device's permanent code in hand: the printed one, or the replacement code a maker's upgrade generated, as Eve does. Without it the reset locks the device out of every ecosystem.
Could not find the accessory, or no accessory nearby
Causes 2, 5 and 6. The device is not advertising, or there is no Thread hub to hear it, or Bluetooth is off on the phone.
Pairing code expired
Cause 3. Make a new share code and use it within its window.

Questions

Can I use the printed code to add the device to a second app?
Not while it is paired to the first. The first app must share it. After a factory reset the permanent code works again, the printed one or a maker's replacement code, but every ecosystem loses the device and has to be set up afresh.
Why does Apple Home accept the code but Google Home refuse the same one?
Because the device was paired to Apple Home first. Google Home now needs the temporary code Apple Home issues under Turn On Pairing Mode, or the device has to be reset.
The lock's 15 minutes ran out while I was in the app
Kwikset: open the Kwikset app and press Resume Setup. Other locks: close and reopen pairing mode on the lock itself, then scan again.
