Guides

QR code will not scan? Type the setup code in

A scratched, curled or badly lit label does not have to stop a setup. Every Home app has a place to type the code, a few taps deeper than the camera.

Checked against the makers' own pages on 3 November 2026.

Where the typed entry is

Apple Home
Add Accessory, then More options. Pick the accessory if it is listed; if not, My Accessory Isn't Shown Here, then Enter Code. It takes the 8 digit HomeKit code and the 11 or 21 digit Matter code, with or without the dashes. For ecobee, choosing the thermostat here puts the code on its screen.
Google Home
Add, then Device. When the scanner opens, Google's page says to tap Add a different way and search the brand; maker guides call the same step Set up without QR code. Paste the 11 digit Matter code. Google Home does not take HomeKit codes.
Amazon Alexa
Devices, the plus, Add Device, the Matter icon, Yes, then Try Numeric Code Instead. Type the 11 digit Matter code. Alexa does not take HomeKit codes.
Samsung SmartThings
Add, Add Device, then Enter under Enter setup code for the 11 or 21 digit Matter code. For a Z Wave device, Add device manually and type the first five digits of the DSK, the group printed first and often underlined.

Reading a worn label

Know the shape first
HomeKit: eight digits as XXX-XX-XXX beside a house mark. Matter: eleven digits, usually printed as XXXX-XXX-XXXX beside the Matter mark, or twenty one. Z Wave: groups of five digits, the first group is the PIN. If the digits you see do not fit one of those, you are reading the serial number or the MAC address.
Let the check digit decide
A Matter code's last digit checks the other ten. Paste what you read into the decoder; if it passes, type that. If it fails, swap the doubtful digit (0 and 8, 1 and 7, 3 and 8, 5 and 6) and try again.
Photograph it before it gets worse
A phone photo in good light, from straight above, usually reads better than the eye. It is also the copy you keep. SmartHomeQR scans the QR code from the camera or a photo and reads supported printed codes from the label text, then saves them together.

Questions

Does typing the code pair the device the same way as scanning?
For Matter, yes: the Home app finds the device by the short discriminator and proves possession with the passcode, both of which are in the 11 digits. For HomeKit, the eight digits are the whole secret.
The Home app turned my 482-19-735 into 4821-9735
An owner on Apple's forum saw the same display change. A respondent there said both groupings mean the same eight digits and suggested typing the code in by hand; the change itself is not a sign of a wrong code.
Can I scan the QR code from a photo instead?
The Home apps want the camera on the label. SmartHomeQR can read a QR code from a photo you already took, then show it fullscreen for the Home app to scan.
