Where the LIFX HomeKit and Matter codes are

LIFX labels the HomeKit code with HK: so you can tell it from the serial number, and lists where it sits on every product.

Checked against the makers' own pages on 3 November 2026.

Where the code is

HomeKit era lights
Printed on the back of the product manual and on the product, marked HK: ###-##-###. A19, Mini and GU10: below the serial number. BR30: to the right of the serial number, under the rubber seal. Lightstrip and Beam: on the back of the controller. Tile: on the master tile only. Downlight: etched on the casing.
Code recovery
Exists only for lights that shipped without a code: Light Settings, HomeKit Status, PAIR, GET CODE in the LIFX app. It does not apply to lights that shipped with one.
Matter lights
Look for the QR code with the Matter logo and an 11 digit code. LIFX: save it before installation, especially for hard to reach fixtures.
Sharing a Matter light
LIFX app, Light Settings, Share Device with another service. iOS generates a Matter setup code. Android hands the light over without a code, except when sharing to an iOS ecosystem, where a code is generated and scanned.
