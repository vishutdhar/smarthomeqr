Guides

Where the Nanoleaf pairing code is

Turn the controller over. Nanoleaf prints the pairing code on the back of the controller or the base of the bulb, and again on the welcome card.

Checked against the makers' own pages on 3 November 2026.

Where the code is printed

Controller or bulb base
Nanoleaf: the 8 digit pairing code, or the 11 digit pairing code on Matter devices, is found on the back of your controller or bulb base, or on the quick start guide or welcome card. Some products also pair by an NFC tap.
Lost
Each controller or bulb base carries a QR code and or 8 digit code. If none can be found, submit a ticket with the serial number, which usually starts with S1 or S2, under Software Support, Pairing or Setup Issues, Misplaced or Lost Pairing Code.
Matter over Wi-Fi
For a device the Nanoleaf app already has, the app can create a pairing code to copy, or a QR code to scan from another phone, from Device Settings, under Connections. A device already commissioned by another ecosystem must be shared from that ecosystem instead. Nanoleaf strongly recommends pairing in the Nanoleaf app first, and resetting the device after a failed attempt.
