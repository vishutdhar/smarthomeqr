Where the Yale Assure Lock HomeKit and Matter codes are

Take the battery cover off. Yale puts the codes on the side of the battery compartment, and repeats the setup QR on the quick start guide.

Checked against the makers' own pages on 3 November 2026.

Where the code is printed

Assure Lock 2
Remove the battery cover. The QR code and the serial number are on the side of the battery compartment. Yale locks with a Smart Module use the code on the module instead.
Assure Lock 2 Touch (YRD450)
The manual calls it the 8 digit HomeKit accessory code located on the side of the lock under the battery cover, and says the setup QR code can also be found on the quick start guide. HomeKit is switched on from the Yale Access app, under the lock's settings, HomeKit.
No QR, no serial
The Yale Access app lets you pick the model with Use Product Selector instead of typing a serial number.

Matter module

First ecosystem only
Yale's Matter Module FAQ: the lock is only paired using the QR code and enrollment menu for the first ecosystem. For a second one, follow the first ecosystem's own sharing steps.
Where the Matter label is
Yale does not state which face of the Assure Lock 2 Matter models carries the Matter code, or whether the Yale app shows it. Check the battery compartment side and the quick start guide first.
