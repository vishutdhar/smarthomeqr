Guides

Where the Schlage Encode Plus HomeKit code is

Schlage prints the HomeKit label where you will only see it with the lock in your hands: on the inside of the interior assembly. The quick start guide carries a backup.

Checked against the makers' own pages on 3 November 2026.

Where the code is printed

Encode Plus (BE499WB)
On the HomeKit setup label on the inside of the interior portion of the lock, behind the battery cover. The quick start guide says to tap your iPhone to the HomeKit label, or to type the 8 digit HomeKit setup code printed on it into the Home app.
The backup on the guide
The quick start guide has a box marked Place label here for the backup codes, and the default user codes are on a label under the battery cover and on the back of the guide. Schlage says you will need these codes if you ever factory reset the lock.
Schlage Sense
The older HomeKit lock keeps its HomeKit label in the same place, on the inside of the interior portion, or on its quick start guide.

Pairing it

Pairing mode
Press the black button inside the interior assembly. A slow blue flash means the lock is ready to pair. Then scan the label or type the code in Apple Home.
Code lost
Whether the Schlage Home app can show the HomeKit code after pairing is not something Schlage documents. Keep the lock paired, and if it must be reset, Schlage support is the route, with the lock's serial number.

Questions

Is the HomeKit code the same as the programming code?
No. The programming code changes the lock's settings and the user codes unlock it at the keypad. The 8 digit HomeKit code, beside the house mark, pairs the lock with Apple Home.
