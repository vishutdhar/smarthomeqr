Lost your HomeKit setup code? What still works

The eight digit code beside the house mark is the only key to a HomeKit accessory, and Apple keeps no copy you can read. Before you give up on a device, work through the places it can still be.

Checked against the makers' own pages on 3 November 2026.

First, what the code looks like and where it hides

A HomeKit setup code is eight digits printed as XXX-XX-XXX next to a small house mark, usually under or beside a QR code. Every unit has its own.

On the accessory
Often somewhere you have not looked: inside a battery cover (August, Yale, Schlage, Wemo Stage), on the underside of a hub (Lutron, eufy HomeBase), behind a wall plate (Leviton), on the neck of a bulb, or on a mounting plate. The brand pages list the exact spot for each maker.
On the box and the quick start card
Most makers print a second copy on the packaging or the leaflet. Schlage even leaves a box on its guide marked Place label here. If you kept the box, check every face, including inside the lid.
Inside the maker's app
Some apps show the HomeKit code for a device that is set up in them: Meross (Device Settings, Device Info, HomeKit setup code), TP-Link Tapo and Kasa (an electronic QR code to save), Aqara Home for the Camera E1, the IKEA Home smart app for DIRIGERA. LIFX can recover a code only for lights that shipped without one.
On the device's own screen
ecobee thermostats never had a sticker. Main Menu, General, Settings, HomeKit, then Enable HomeKit pairing puts the QR code on the thermostat's screen. HomePod has no code at all: setup is by holding an iPhone near it, with a four digit passcode Siri speaks as the fallback.

If the accessory is already in your home, you may not need it

Keep it paired and it keeps working
A paired accessory does not ask for its code again. Moving it to another room, renaming it, updating iOS, or adding people to your home needs nothing. The code is only needed to pair again.
Apple shows no code for a paired accessory
There is no place in the Home app or in Settings that reveals the eight digit code of an accessory you already paired. Apple's own lost code advice is to check the accessory, its manual, and to contact the maker.
Do not remove the accessory to fix a problem
Removing it from the Home app, resetting it, or deleting the home all put it back to the state where the code is required. Try restarting the accessory and the home hub first.
Accessory already in another home
That message means the accessory still holds a pairing from a previous home or owner. It needs a reset on the accessory itself, after which the printed code is required to pair it again.

When the code is truly gone

Ask the maker, with the serial number
Makers differ. Nanoleaf takes a ticket with the serial number. Meross lists a factory mode route and then support with the purchase invoice. Aqara asks for the device id or serial. Eve says the code is not retrievable and the device has to be replaced.
Check whether the device has moved to Matter
Leviton Decora Smart Wi-Fi after firmware 2.1.0 and Eve devices after their Matter upgrade no longer accept the HomeKit sticker. Their Matter code lives in the maker's app and is the one to use.
Wemo
Belkin ended Wemo cloud and app support on January 31, 2026, and says no new HomeKit setups are possible after that date for the Wi-Fi models. Already paired Wemo devices and the Thread based ones keep working.
A replacement is sometimes the honest answer
For an accessory with no app route and no maker recovery, the printed code is the only key. If it is gone, the accessory cannot be paired with any Home again.

So it does not happen again

Scan or photograph every label before the device goes on the wall, in the ceiling or behind the cabinet. Keep the quick start card in one folder. And save the code somewhere you will find it in three years: SmartHomeQR scans the label once and keeps the code, the maker and the model by home and room, offline, on iPhone, iPad, Apple Watch and Android.

Questions

Can the Home app show me the code of an accessory I already paired?
No. Apple documents no such screen, and its lost code advice is to check the accessory, the manual and the maker. Keep the accessory paired and you will not need the code.
I typed the code and the Home app says the setup code is incorrect
Check 0 against 8, 1 against 7 and 3 against 8 on a worn label, type it with the dashes or without, and make sure the accessory is actually in pairing mode and not already paired elsewhere. If it keeps failing, the maker can check the label from a clear photo.
The Home app reformatted my code to four and four digits
An owner on Apple's forum saw the same. A respondent there said both groupings mean the same eight digits and suggested typing the code in by hand; the display change itself is not a sign of a wrong code.
Is a Matter code the same thing?
No. Matter codes are 11 or 21 digits and work differently once a device is paired. See Lost your Matter pairing code.
