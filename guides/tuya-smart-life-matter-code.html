Where a Tuya or Smart Life Matter code is

Tuya powers many white label brands, so the sticker's spot varies by product. What stays the same is the app: it pairs with the printed code and shares with a temporary one.

Checked against the makers' own pages on 3 November 2026.

Where the code is

Adding in the Tuya app
Plus, Scan, then scan the QR code on the device or enter the 11 digit pairing code.
Sharing out
The device, the three dot menu, Share Device, then Share over Matter for a code or Share with QR Code. Tuya: the sharing code is one time use and time limited, and the pairing code and sharing code are different; the pairing code is used for the initial activation.
Zigbee behind a gateway
Those devices have no Matter code of their own. Share the gateway instead, with Share via Matter Gateway.
On the device
Because the label belongs to the white label brand, the printed location varies per product. Check the device, its box and its leaflet.
