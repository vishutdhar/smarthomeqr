Where the Wemo HomeKit code is, and the January 2026 cutoff

Wemo's code is on the back of the device and in the guide. The bigger fact is the date: after January 31, 2026, Belkin says a Wi-Fi Wemo cannot be set up with HomeKit again.

Checked against the makers' own pages on 3 November 2026.

Where the code is

On the device and in the guide
Belkin: the Apple HomeKit code is provided in the Quick Install Guide and can also be found at the back of the Wemo device. Each unit's code is unique.
Wemo Mini
The 2nd generation Mini has the code on a sticker on the back and in the quick start guide. The 1st generation Mini has no HomeKit label and had to be connected through the Wemo app.
Wemo Stage (Thread)
The code is in the quick start guide and on the back of the unit after removing the battery cover.

The cutoff

Belkin ended Wemo cloud and app support on January 31, 2026. Its notice says that after that date you will no longer be able to set up a Wemo device with Apple HomeKit. Devices already paired keep working locally, and Thread based Wemo devices are not affected. So for a Wi-Fi Wemo, do not remove it from the Home app or reset it: the printed code will not bring it back.
