Setup code guides

Where the code is printed, brand by brand, and what still works when it is gone. Each page is checked against the maker's own support pages, with the sources listed.

The problem pages

Lost HomeKit code
Apple shows no code for a paired accessory. This page lists where the sticker hides, which apps show the code, and when a replacement is the only way.
Lost Matter pairing code
A Matter code is needed at first setup and after a reset. It can still be on the device, in the box, in the maker's app, or shared from the first app.
Where the code is printed
The exact spot each of 28 makers prints its HomeKit or Matter code is listed here: battery covers, wall plates, bulb necks, apps and screens.
Matter code not working
A correct Matter code can still be refused: already added, pairing window closed, code expired, no Thread hub. Each cause has its own fix here.
Type the code in
Apple Home, Google Home, Alexa and SmartThings each have a place to type the code. This page shows where, and which codes each one takes.

Brand by brand

Amazon Echo and Alexa
An Echo has no Matter code of its own. Alexa takes the accessory's QR or 11 digit code, shares with a 15 minute code, and needs a Thread Echo for Thread.
Aqara
Aqara Camera E1 shows its HomeKit code in the Aqara Home app, and Aqara's forum staff say a lost Matter code cannot be restored. Here is what Aqara says.
August
August prints the August and HomeKit QR codes on the serial label inside the front battery cover. Press the August logo on the faceplate to open it.
Eve
Eve prints the HomeKit code on the accessory and in the quick start guide. After the Matter upgrade a new Matter setup code replaces it, kept in the Eve app.
Google Nest
Matter capable Nest devices reach Apple Home, Alexa and SmartThings from Google Home: device settings, Linked Matter apps and services, a temporary code.
Govee
Govee prints the Matter QR code or device number on the product and shows it again in the Govee Home app. Set it up within 15 minutes of power on.
HomePod and Apple TV
HomePod pairs by holding an iPhone near it, Apple TV joins from its settings. Neither has a code: Matter codes come from the accessory, not the hub.
IKEA DIRIGERA
IKEA Matter devices carry the QR code on the yellow cover in the box and an 11 digit code on the device or packaging. DIRIGERA shows its HomeKit code in-app.
Kwikset
Kwikset Halo Select converts to Matter in the Kwikset app, then the Matter QR on the lock is scanned once. Extra ecosystems get a code from the first app.
LIFX
LIFX prints the HomeKit code as HK: ###-##-### on the light, below the serial on most models, and on the back of the manual. Matter lights have a Matter QR.
Level
Level publishes no page on where its code is printed. Owners report the back of the quick start guide, and the underside of the original Level Lock.
Leviton Decora Smart
Leviton prints the Gen 2 HomeKit QR code in the lower right corner behind the wall plate. After the Matter update the code comes from the My Leviton app.
Lutron Caseta
Only the Lutron Smart Hub has a HomeKit code, printed on its underside. Dimmers and switches have none; they reach Apple Home through the hub.
Meross
Meross shows the HomeKit setup code in its app under Device Settings, Device Info, and documents a factory mode route for a device deleted from iOS.
Nanoleaf
Nanoleaf prints the 8 digit HomeKit or 11 digit Matter code on the back of the controller or bulb base and on the welcome card. Lost codes go to support.
Philips Hue
Hue Matter bulbs print the 11 digit code on the bulb and the QR code in the installation guide. With a Hue Bridge, the codes come from the Hue app.
Ring
Ring Alarm and most Ring devices carry a Ring QR code and a 5 digit code, usually on the back, for the Ring app. No HomeKit code, and no Matter was found.
SONOFF
SONOFF prints the Matter QR code in the quick guide and shows the numeric setup code in the eWeLink app under Device Settings, with Enable Pairing Mode.
Schlage
Schlage Encode Plus prints its HomeKit setup code on the interior assembly under the battery cover, with a backup label on the quick start guide.
Sengled
Sengled Matter Wi-Fi bulbs ship with the Matter QR code on the quick start guide. The code works for the first ecosystem only; a power cycle reopens pairing.
SmartThings
SmartThings adds Matter devices by QR or the 11 or 21 digit code, Z Wave devices by the first five DSK digits, and shares Matter devices with its own code.
SwitchBot
SwitchBot Hub 2 has its Matter QR code on the side or back, and the SwitchBot app shows the code under Matter Setup. Wi-Fi devices get it from the app.
TP-Link Tapo and Kasa
TP-Link prints the Matter code on the side of a plug, the neck of a bulb or beside a switch, adds a backup sticker in the box, and shows it in the Tapo app.
Tuya and Smart Life
Tuya based devices pair with the QR code on the device or the 11 digit code, and share from the Tuya or Smart Life app with a one time, time limited code.
Wemo
Wemo prints the HomeKit code on the back of the device and in the quick install guide. Belkin says Wi-Fi Wemo devices cannot join HomeKit after January 2026.
Yale
Yale Assure Lock 2 keeps its QR code and HomeKit code on the side of the battery compartment, with the setup QR on the quick start guide.
ecobee
ecobee thermostats have no HomeKit sticker. The QR code appears on the thermostat's own screen under Settings, HomeKit, or when the Home app asks for it.
eufy
eufy prints the HomeKit setup code on the bottom of HomeBase 2. A system already in the eufy app can enable HomeKit from HomeBase Settings instead.
