Setup code guides

Where the code is printed, brand by brand, and what still works when it is gone. Each page is checked against the maker's own support pages, with the sources listed.

The problem pages

Lost HomeKit code
Apple has no screen that shows a paired accessory's HomeKit code. Where to look, which makers' apps show the code, and when a reset or a replacement is the only way.
Lost Matter pairing code
A Matter QR code and its 11 digit code are needed at first setup and after a reset. Where to find them again: the device, the box, the maker's app, or a share code from the app that already has the device, which your iPhone's Matter list can name.
Where the code is printed
The exact spot each maker prints its HomeKit or Matter setup code: under battery covers, behind wall plates, on bulb necks, in apps and on screens. 28 brands, each checked against the maker's own pages.
Matter code not working
Setup code incorrect, pairing code expired, accessory already added, no Thread hub: why a correct Matter code is refused and what fixes each case.
Type the code in
Where the manual code entry is in Apple Home, Google Home, Amazon Alexa and SmartThings, and which codes each one takes: 8 digit HomeKit, 11 or 21 digit Matter, Z Wave PIN.

Brand by brand

Amazon Echo and Alexa
Echo devices are Matter controllers and have no code to scan. Alexa takes the accessory's QR or 11 digit code, shares devices with a 15 minute code under Other Assistants and Apps, and needs a Thread enabled Echo for Thread devices.
Aqara
Aqara Camera E1 can show its HomeKit code in the Aqara Home app. For a lost Matter code, Aqara's forum staff say it cannot be restored. Where the codes are and what Aqara says.
August
August prints the August and Apple HomeKit QR codes on the serial number label inside the front battery cover. Press the August logo at the bottom of the faceplate to open it.
Eve
Eve prints the HomeKit code on a sticker on the accessory and in the quick start guide. After the Matter upgrade a new Matter setup code replaces it, stored in the Eve app.
Google Nest
Nest devices that support Matter reach Apple Home, Alexa and SmartThings through Google Home's sharing: device settings, Linked Matter apps and services, then a pairing code or QR code. Google's setup fixes cover restarts and resets, not lost codes.
Govee
Govee prints the Matter QR code or device number on the product and shows it again on the Device Settings page in the Govee Home app. First setup must happen within 15 minutes of power on.
HomePod and Apple TV
HomePod sets up by holding an iPhone near it, with a four digit Siri passcode as the fallback. Apple TV becomes a home hub from its settings. Both are controllers, so the Matter code comes from the accessory, not from them.
IKEA DIRIGERA
IKEA Matter devices carry the QR code on the yellow cover in the packaging and an 11 digit code on the device or packaging. DIRIGERA's HomeKit code is shown in the IKEA Home smart app, not on a sticker.
Kwikset
Kwikset Halo Select converts to Matter from the Kwikset app, then the Matter QR code on the lock is scanned once. Extra ecosystems use the 11 digit code from the first smart home app.
LIFX
LIFX prints the HomeKit code as HK: ###-##-### below the serial number on most lights and on the back of the manual. Matter lights carry a Matter QR and 11 digit code. The app shares Matter lights to other platforms.
Level
Level publishes no page on where its HomeKit or Matter code is printed. Owners report it on the back of the quick start guide for Level Bolt and Level Lock Plus, and on the underside of the original Level Lock.
Leviton Decora Smart
Leviton prints the Gen 2 HomeKit QR code in the lower right corner behind the wall plate. After the Matter firmware update the sticker stops working and the Matter code comes from the My Leviton app.
Lutron Caseta
Only the Lutron Smart Hub has a HomeKit code, printed on its underside. Dimmers and switches have none; they reach Apple Home through the hub.
Meross
Meross shows the HomeKit setup code inside its app under Device Settings, Device Info, and documents a factory mode route for a device that was deleted from iOS. Last resort: support with the invoice and the original Wi-Fi name.
Nanoleaf
Nanoleaf prints the 8 digit HomeKit code, or the 11 digit Matter code, on the back of the controller or bulb base and on the quick start guide. Lost codes go to support with the serial number.
Philips Hue
Hue Matter bulbs print the 11 digit code on the bulb and the QR code in the installation guide. With a Hue Bridge, Apple Home is set up from the Hue app and Matter codes come from the app.
Ring
Ring Alarm and most Ring devices carry a Ring QR code and a 5 digit code, usually on the back, scanned in the Ring app; on alarm devices the digits are the Z Wave PIN. Ring publishes no HomeKit code, and no Matter support was found.
SONOFF
SONOFF prints the Matter QR code in the product's quick guide and shows the numeric setup code in the eWeLink app under Device Settings, where Enable Pairing Mode also makes a QR code or a code to copy.
Schlage
The Schlage Encode Plus prints its HomeKit setup code on the interior assembly under the battery cover, with a backup label on the quick start guide. Where to look, how to pair, and what to do without it.
Sengled
Sengled Matter Wi-Fi bulbs ship with the Matter QR code on the quick start guide. The code works for the first ecosystem only; pairing mode closes after 15 minutes and reopens with a power cycle.
SmartThings
SmartThings adds Matter devices by QR or the 11 or 21 digit code, Z Wave devices by QR or the first five DSK digits, and shares Matter devices with a code that differs from the label. Hubs are added by QR or Scan Nearby.
SwitchBot
SwitchBot Hub 2 has its Matter QR code on the side or back, and the SwitchBot app shows the code under Matter Setup. Matter over Wi-Fi devices get their code from the app after a reset step.
TP-Link Tapo and Kasa
TP-Link prints the Matter code on the side of a plug, the neck of a bulb or beside a switch button, adds a backup sticker in the box, and shows the code again in the Tapo or Kasa app under Device Info.
Tuya and Smart Life
Tuya based devices pair with the QR code on the device or the 11 digit pairing code, and share from the Tuya or Smart Life app with a one time, time limited sharing code. Zigbee devices behind a Tuya gateway share through the gateway.
Wemo
Wemo prints the HomeKit code on the back of the device and in the quick install guide. Belkin ended Wemo app support on January 31, 2026, and says no new HomeKit setups are possible after that for Wi-Fi models; Thread models are exempt.
Yale
Yale Assure Lock 2 keeps its QR code and HomeKit code on the side of the battery compartment, with the setup QR on the quick start guide. The Matter module's printed QR pairs the first ecosystem only.
ecobee
ecobee thermostats have no HomeKit sticker. The QR code appears on the thermostat's own screen under Main Menu, General, Settings, HomeKit, or when the Home app asks the thermostat to display it.
eufy
eufy prints the HomeKit setup code on the bottom of HomeBase 2. A system already in the eufy app can enable HomeKit from HomeBase Settings without the printed code.
