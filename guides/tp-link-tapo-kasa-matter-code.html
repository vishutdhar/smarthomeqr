Where the TP-Link Tapo and Kasa Matter and HomeKit codes are

TP-Link is the model citizen: a code on the device, a backup sticker in the box, and the same code in the app after setup.

Checked against the makers' own pages on 3 November 2026.

Where the code is

On the device
Plugs carry the Matter code on the side. Bulbs have it in the middle of the casing, just below the light sphere and above the base. Switches have it on the side near the button.
In the box
A backup Matter code sticker is included inside the product box in case the code on the device becomes damaged or unreadable.
In the app
After setup: Device Settings, Device Info, Matter Setup Code. TP-Link suggests saving it to the phone's photo album. For a lost sticker, set the device up in the Tapo or Kasa app first, then retrieve the code there.
HomeKit models
Download and save the HomeKit electronic QR code in the Tapo or Kasa app, then scan it from the screen in the Home app. For a persistent setup code incorrect error, TP-Link support asks for a clear picture of the QR label.

Timing

First setup
Matter setup is available for 15 minutes after power on. Longer than that, power cycle the device.
Sharing
A Google Home pairing code expires in 3 minutes. Apple Home needs 5 minutes between new codes, and shows Copy Code in the pairing sheet.
