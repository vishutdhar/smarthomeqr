Google Nest and Matter: sharing from Google Home

A Matter capable Nest device has no sticker you scan into Apple Home. The code comes out of the Google Home app, for a few minutes at a time. Which Nest models support Matter is on Google's own list; this page covers the sharing step only.

Checked against the makers' own pages on 3 November 2026.

Where the code comes from

Google Home
Open the device's settings, Linked Matter apps and services, Link apps and services, then Use pairing code or Share with QR code to generate a temporary pairing or QR code. TP-Link reports Google's code expires in about 3 minutes.
On the thermostat
Owners describe Settings, Matter, Link another app, Scan code on the Nest Learning Thermostat (4th generation). Google's community answer did not render when this page was checked, so take it as owner reported.
When a third party device fails to set up
Google's Matter setup page is written for third party devices, not Nest devices, and its sequence is: restart the accessory, close the Google Home app, clear its cache, restart the phone, reopen Google Home and try again, and contact the manufacturer if that fails, with a factory reset only where the maker calls for one. It does not cover lost codes. For a Nest device itself, Google's Nest help is the reference. A reset puts a third party device back to needing its printed code, so make sure you have that code first.
