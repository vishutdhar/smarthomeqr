Where the Philips Hue HomeKit and Matter codes are

Hue has two routes. Bulbs used without a bridge carry a Matter code printed on the bulb. With a bridge, the codes come out of the Hue app, and the old sticker on the bridge matters less than it used to.

Checked against the makers' own pages on 3 November 2026.

Where the code is

Matter bulbs without a bridge
Scan the QR code on the installation guide, the Matter QR code, or enter the 11 digit pairing code. Lost the guide: Philips says to use the manual pairing code printed on the bulb.
With a Hue Bridge
The Matter link is made in the Hue app under Settings, Smart Home. For each additional platform, use the original app to generate a new Matter setup code.
Apple Home today
Hue's current Apple Home page no longer asks you to scan a code on the bridge. The flow is Settings, Smart home and voice, Get started, Siri and Apple Home, Set up, then sign in with a Hue account.
The sticker under the bridge
The square Hue Bridge has a HomeKit code printed on its underside, according to many owners, but Philips' current pages do not mention it. If a HomeKit setup still asks for it and the sticker is gone, the suggestion on owner forums is to call Philips with the serial number.
In the Hue app
Products are added by QR. If a product has no QR code, tap No QR code and add it by searching or by its serial number.
